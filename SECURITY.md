# Security Policy

## Supported Versions

This is a static landing page with no backend, authentication, or user data collection.
There are no versioned releases — the live site always reflects the latest deployment from the `main` branch.

| Version | Supported |
|---------|-----------|
| Latest (main) | ✅ |

## Reporting a Vulnerability

If you discover a security vulnerability in this project, please report it responsibly.

**Do not open a public GitHub issue for security vulnerabilities.**

Instead, contact the developer directly:

- 📧 Email: letieri.dev@gmail.com
- 💼 LinkedIn: https://www.linkedin.com/in/kaykiletieri/

Please include in your report:
- A description of the vulnerability
- Steps to reproduce the issue
- Potential impact
- Any suggested fix (optional)

I will respond within **48 hours** and work to resolve confirmed vulnerabilities as quickly as possible.

## Scope

This project is a static frontend site. The following are considered in scope:

- Cross-site scripting (XSS)
- Malicious dependency injection
- Sensitive data exposure via source code

The following are **out of scope**:

- Issues in third-party services (GitHub Pages, Cloudflare, Google Fonts)
- Social engineering attacks
- Denial of service attacks

## Acknowledgements

Responsible disclosure is appreciated. Thank you for helping keep this project safe.
